**Topic:** Git Commits

## Question

What makes a Git commit small, logical and meaningful?

## Notes

A good Git commit is an atomic, self-contained snapshot that handles a single problem or step, leaves the code in a working state, and uses a clear, imperative message. Opinions on Stack Overflow show mixed preferences on absolute commit frequency, but developers agree that structure matters.
